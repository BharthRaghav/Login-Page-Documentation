# Online Banking — Business Analysis Case Study
## Project Overview
This project demonstrates an end-to-end Business Analysis workflow for an Online Banking enhancement. The objective is to document how customers can access online banking through a login and new-user registration process, supported by clearly defined functional requirements, business rules, process flows, and test scenarios.
The project focuses on translating business needs into structured documentation that can help business stakeholders, developers, and QA teams understand the expected system behavior.

**Project type**: Business Analysis Portfolio Case Study.

**Domain:** Banking / Financial Services

**Primary focus**: Requirements Engineering, Login & Registration Workflows, Functional Documentation, and Test Case Design.

_This is a portfolio case study based on a banking scenario, not an official Bank of America project or an implementation of its production systems._
